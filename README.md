# 📖 Sobre

O **Terminal Zero** é um jogo 2D do gênero **Puzzle**, desenvolvido como atividade acadêmica da disciplina de **Raciocínio Lógico**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da **FAMINAS**, sob orientação do professor **Nícollas Cretton**.

O jogo transporta o jogador para um ambiente inspirado em terminais e sistemas computacionais, onde cada fase representa um novo desafio lógico a ser solucionado.

Mais do que um jogo, o projeto busca estimular o pensamento analítico, a resolução de problemas e o raciocínio lógico de forma interativa.

# 🎯 Objetivo

```text
MISSÃO ATUAL

> Invadir o sistema.
> Resolver todos os puzzles.
> Superar os níveis.
> Concluir a operação.
```

Cada fase apresenta novos desafios que exigem observação, estratégia e tomada de decisão.

À medida que o jogador avança, a complexidade dos puzzles aumenta, exigindo cada vez mais raciocínio lógico.

---

# 🎮 Mecânicas Principais

* 🧩 Resolução de puzzles lógicos.
* 📈 Progressão de dificuldade.
* 🧠 Desafios baseados em raciocínio.
* 🎯 Interação com objetos do cenário.
* 🖥 Interface inspirada em terminais hackers.

# 🚀 Como Executar

Clone o repositório:

```bash

```

Entre na pasta:

```bash
cd terminal-zero
```

Abra o projeto no navegador ou na plataforma utilizada durante o desenvolvimento.
